承認に答える。答えは 3 種類ある。`allow` は今回だけ許可する。`allowAlways` は許可し、同じ規則に当たる使用を以後は聞かない。`deny` は拒否する。

`comment` は拒否の理由で、`deny` のときだけ付けられる。付けると理由として AI に渡り、AI は作業を続ける。付けなければ、その実行を終える。待っている入力は捨てず、続けて動く。ここが `POST /conversations/{id}/stop` と違う。`allow` や `allowAlways` に `comment` を付けると、400 を返す。

答えはどの client からでも送れる。先に届いた答えで確定する。確定すると承認は消え、結果を付けた `approval.resolved` が流れる。後から届いた答えには、承認が既に無いので 404 を返す。期限が過ぎた承認と打ち切られた承認も消えているので、404 を返す。

期限が過ぎた承認は、理由の無い拒否と同じく実行を終える。

`allowAlways` で覚える規則は、server 全体で 1 つの許可として残る。会話ごとや作業ディレクトリごとの単位ではない。覚えた規則を取り消す操作は API に無い。

`rules` を持たない承認に `allowAlways` で答えると、400 を返す。
