全会話のイベントが 1 本に流れる。流すのは会話に関するイベントだけで、すべてのイベントが `conversationId` を持つ。会話に属さないもの (ログ等) は流さない。承認や質問を将来足す場合も、要求の通知はここに流し、回答と取り直しは別の path で受ける。

会話が処理中かどうかは `conversation.status` で届く。`busy` は、実行中の Turn があるか、待っている入力がある状態である。`idle` は、どちらも無い状態である。入力を受理して `idle` でなくなったときと、実行が終わり待っている入力も無くなったときに流れる。

切断中のイベントは再送しない。

イベントは追加のみで増える。client は未知の `event` を無視する。
