会話の設定を丸ごと置き換える。`model` と `effort` はどちらも必須である。

会話は作らない。存在しない ID を指した場合は 404 を返す。

実行中と、承認や質問の答え待ちのどちらでも受け付ける。実行中の実行は承認や質問を待っている実行も含めて元の設定のまま続き、待っている承認と質問はそのまま残る。置き換えの後に始まる実行は新しい設定を使う。置き換えの時点で待っている入力も、新しい設定で実行する。

設定が変わると `conversation.updated` が流れる。今と同じ内容で置き換えた場合は流れない。

server が受け付けない値や未知の項目は 400 で弾く。
